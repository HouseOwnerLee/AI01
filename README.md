# KDT 13기 AI & Big Data Engineering

인공지능 및 빅데이터 과정을 통해 수행한 학습 기록 및 프로젝트 포트폴리오 저장소입니다. 데이터 수집부터 분석, 시각화, 머신러닝·딥러닝·컴퓨터 비전·자연어 처리 모델 구축 및 데이터베이스 연동까지 전 과정을 포함하고 있습니다.

---

## 🛠️ Tech Stack & Topics

* **Data Analysis & Visualization**: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`
* **Web Crawling & Data Collection**: `BeautifulSoup`, `Selenium`, OpenAPI / REST API
* **Machine Learning & Deep Learning**: `Scikit-learn`, `TensorFlow`, `PyTorch`
* **Computer Vision**: `OpenCV`, `YOLO` (You Only Look Once)
* **Natural Language Processing (NLP)**: KoNLPy, Text Preprocessing, AI NLP Models
* **Database**: `SQL` / RDBMS

## 🚀 Key Highlights

1. **End-to-End 데이터 파이프라인 경험**
   * API 및 크롤링(BeautifulSoup, Selenium) 기술로 비정형 데이터를 직접 수집하고 DB 구축 및 분석 모델까지 연동
2. **컴퓨터 비전 및 NLP 모델 구현**
   * YOLO 객체 탐지 알고리즘 적용 및 한국어 NLP 전처리 기술을 통한 AI 응용 모델 구축
3. **7회 단계별 미니 프로젝트**
   * 다양한 실무 시나리오 기반 미니 프로젝트(`mini_project_01` ~ `07`) 수행을 통해 문제 해결 능력 도출
